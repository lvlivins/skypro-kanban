## Описание 

Приложение для управления задачами в формате канбан-доски, где пользователь может:
<br>```- зарегистрироваться,```
<br>```- войти в аккаунт,```
<br>```- создавать,```
<br>```- редактировать,```
<br>```- удалять и просматривать задачи,```
<br>```- менять их статус,```
<br>```- получать сообщения об ошибках при работе с сервером.```
